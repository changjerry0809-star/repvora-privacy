隱私權政策

核心承諾:本 App 不蒐集、不上傳、不分享任何可識別您身分的個人資料。並且在使用過程中,不會向任何外部伺服器發送網路請求。

1. 零資料蒐集

本 App 完全不會蒐集下列任何資料:

  • 姓名、電話、電子郵件、生日、性別
  • 位置資訊(GPS / 基地台 / Wi-Fi)
  • 聯絡人、通話紀錄、簡訊
  • 相簿、相機、麥克風內容
  • 裝置識別碼(IMEI、Android ID、IDFA / IDFV、廣告 ID)
  • 使用行為追蹤(開啟時間、點擊事件、停留時間等)
  • 任何第三方分析服務(本 App 不使用 Google Analytics、Firebase、Facebook SDK、AppsFlyer、Sentry 等任何追蹤 SDK)

2. 完全離線運作

本 App 不含任何對外網路請求:

  • 字型全部採用系統內建(Apple PingFang TC / Android Noto Sans CJK TC / Windows 微軟正黑體),不會從 Google Fonts 或任何 CDN 下載
  • 無廣告 SDK
  • 無遠端設定載入
  • 無遠端錯誤回報
  • 無遠端功能開關

您可以在飛航模式下完整使用本 App 所有功能。

3. 您輸入的資料

您在本 App 中建立的所有內容(訓練紀錄、行程、身體數據、自訂動作、設定等),完全儲存於您裝置本地的 localStorage 中,我們無法存取、查看或接收。資料不會自動同步到 iCloud、Google Drive 或任何雲端。

4. 權限說明

權限用途必要
通知本地訓練排程提醒否(可關閉)
震動 / 觸覺回饋操作回饋、PR 達成提示否

本 App 不會請求 位置、相機、麥克風、聯絡人、照片、Face ID / Touch ID、追蹤、網路等權限。

5. 資料備份與還原

您可透過「我的 → 設定 → 匯出資料」產生 JSON 備份檔。此檔案由您本人保管與傳輸,我們不經手、不儲存。

6. 兒童隱私

本 App 不特別針對 13 歲以下兒童設計,也不會刻意蒐集未成年人資料(因為我們根本不蒐集任何人的資料)。

7. 政策變更

若本政策未來有重大變更,我們會於 App 內或商店資訊中公告。

8. 聯絡我們

請透過 App Store / Google Play 商店的「開發者聯絡資訊」與我們聯繫。

Privacy Policy

Core pledge: The App does NOT collect, upload, or share any personally identifiable information, and makes NO outbound network requests during normal operation.

1. Zero Data Collection

The App collects none of the following:

  • Name, phone number, email, birthday, gender
  • Location (GPS / cell tower / Wi-Fi)
  • Contacts, call logs, SMS
  • Photos, camera, microphone content
  • Device identifiers (IMEI, Android ID, IDFA / IDFV, Advertising ID)
  • Usage analytics (session times, click events, dwell time, etc.)
  • Any third-party analytics (NO Google Analytics, Firebase, Facebook SDK, AppsFlyer, Sentry, etc.)

2. Fully Offline

The App makes no outbound network requests:

  • Fonts are provided by the OS (Apple PingFang TC / Android Noto Sans CJK TC / Windows 微軟正黑體). Nothing is downloaded from Google Fonts or any CDN.
  • No ad SDKs
  • No remote configuration
  • No remote crash reporting
  • No remote feature flags

All features work in airplane mode.

3. Data You Create

All content you create — workout logs, schedules, body metrics, custom exercises, templates, settings — is stored exclusively in your device's local localStorage. We have no ability to access, view, or receive this data. Nothing syncs to iCloud, Google Drive, or any cloud automatically.

4. Permissions

PermissionPurposeRequired
NotificationsLocal workout remindersNo (disable in Settings)
Haptics / VibrationHaptic feedback, PR celebrationsNo

The App does NOT request location, camera, microphone, contacts, photos, Face ID / Touch ID, tracking, or network permissions.

5. Backup & Restore

You can export your data as a JSON file via Profile → Settings → Export. This file is created, stored, and transmitted entirely by you. We never handle it.

6. Children's Privacy

Not directed at children under 13. Does not knowingly collect data from minors.

7. Changes

Material changes will be announced in the App or on the store listing.

8. Contact

Via "Developer contact" on the App Store / Google Play listing.
